# P19 Repository Audit Checklist

This is the operational file-by-file convergence ledger for P19. `todo.md`
keeps phase-level work; this document records the exhaustive repository audit.

## Review Protocol

Do not check an item merely because it imports successfully. For every item:

1. Query Graphify for its owner, inbound callers, outbound dependencies, and
   shortest path to a public example or production execution route.
2. Compare Graphify with source imports, runnable examples, benchmarks, and
   tests. Tests alone do not justify retaining production code.
3. Decide whether the content is current, uniquely owned, correctly placed,
   and consistent with `GUIDELINES.md` and the public examples.
4. Keep, merge/move, or delete it. Do not leave compatibility modules at old
   paths. Record the decision directly below the item when it is non-obvious.
5. Run only the smallest relevant tests during the audit. Run broad validation
   at the P19 gate, then run `graphify update .`.

Checked means the item has a recorded final owner and no known duplicate route.
Generated local artifacts may be deleted without source-level tests.
